Graph Neural Network

Scope

Audit of the GNN pipeline (src/graph_builder_app.py, src/graph.py, src/gat_model.py, src/gnn_main.py, src/train_pretrain.py) with its balancing mechanisms (GraphSMOTE in src/graphsmote.py, ImGAGN in src/imgagn.py) and Optuna hyperparameter search.

Conceptual map

  1. Base data: gantries, flows and accidents (src/utils.py).
  2. Feature engineering: snapshot/flow (src/snapshot_pipeline.py, src/features.py).
  3. Manual / guided feature selection and persistence.
  4. Graph: pm nodes, temporal/spatial/st_fwd edges and attributes.
  5. Training: HeteroGAT + TemporalAggregator (optional).
  6. Balancing: GraphSMOTE and/or ImGAGN.
  7. Evaluation: F1, AUC, AUPRC, MCC and thresholds.
  8. Artefacts: models, _hparams.json sidecars, augmented graphs and gnn_history.jsonl.

Graph data model

  • Node: pm (gantry-minute), with pm.y and pm.is_accident_pm.
  • Edges: temporal \(P_{i,t}\to P_{i,t+1}\); spatial \(P_{i,t}\to P_{i+1,t}\); st_fwd optional; spatial_back optional.
  • Attributes: \( \Delta x \) between target and source; extras on spatial (gradients, shock, distance); temporal and st_fwd are zero-padded.
  • Masks: train/val/test_mask with temporal cut and sequence_mask.

HeteroGAT and variants

The base model is src/gat_model.py::HeteroGAT: HeteroConv layers with GATConvSaveAlpha, aggr1 and aggr2 aggregations, attentions captured under XAI=1 used for \(L^2\) regularisation, batch-wise edge_attr validation and optional gradient checkpointing.

Variant registration is controlled by GNN_VARIANT and GNN_TEMPORAL_CACHE_STRATEGY, materialised in _build_gnn_model, _build_temporal_head_for_variant and _prime_temporal_cache_if_needed. Registered variants:

  1. gat_snapshot (baseline).
  2. gat_gru, gat_transformer, gat_attnpool (temporal heads).
  3. gat_edge_mlp, gat_edge_mlp_gru, gat_edge_mlp_transformer (edge encoder + head).
  4. gnn_edge_aware, gnn_edge_aware_gru, gnn_edge_aware_transformer (TransformerConv).

"Five minutes before" labelling

\[ \text{positive interval} = (t+\gamma,\ t+\gamma+H] \]
(6.1)
Variables
γ
Guard band (anti-leakage): minutes between the observed bin and the start of the positive interval.
H
Horizon: length of the interval where the accident is considered.
Implementation
src/graph.py · build_graph (SequenceConfig labelling)

Recommended protocol: GUARD_BAND_MINUTES=5 and HORIZON_MINUTES=5 (or 10–20 for windowed risk).

Temporal cache

incremental keeps a per-batch cache (cheaper, sampler-dependent); global_epoch performs a full forward per epoch for consistent sequences. For scientific work global_epoch is recommended.

Training and loss

train_minibatch in src/train_pretrain.py classifies on pm (first batch_size from NeighborLoader) with

\[ \mathcal{L} = \mathcal{L}_{\text{cls}} + \lambda_{\text{edge}}\mathcal{L}_{\text{edge}} + \lambda_{\text{att}}\mathcal{L}_{\text{att}} \]
(6.2)
Variables
ℒcls
Main binary classification loss on pm.
ℒedge
Edge reconstruction with negative sampling (when edge_gen is on).
ℒatt
L² regularisation over captured attentions (XAI=1).
λedge, λatt
Coefficients tuned by Optuna.
Implementation
src/train_pretrain.py · train_minibatch

\(\mathcal{L}_{\text{edge}}\) is reconstruction with negative sampling (if edge_gen is set). \(\mathcal{L}_{\text{att}}\) is \(L^2\) over attentions when XAI=1. The loop uses gradient accumulation (accumulation_steps=2), grad_clip, OneCycleLR and AMP on CUDA.

GraphSMOTE

  1. Per-minibatch \(\ell^2\)-normalised embeddings.
  2. SMOTE in embedding space: \( \mathbf{z}_{\text{syn}} = (1-\alpha)\mathbf{z}_i + \alpha\mathbf{z}_j \), \(\alpha\sim U(0,1)\).
  3. Per-node-type \(z\to x\) decoders with SmoothL1/MSE and early stopping.
  4. Insertion of synthetic nodes respecting train/val/test_mask.
  5. Edge generation with RelEdgeGen; real candidates via GRAPHSMOTE_CONECT and direction via BIDIRECCTION.

ImGAGN

Generates synthetic nodes as convex combinations of training minority nodes. Defines the synthetic count by:

\[ \lambda_1 = \frac{n_{\min}+n_g}{n_{\text{maj}}}\ \Rightarrow\ n_g = \max(0,\ \lambda_1 n_{\text{maj}} - n_{\min}) \]
(6.3)
Variables
nmin, nmaj
Real minority and majority training nodes.
ng
Synthetic nodes to generate to reach target ratio λ₁.
λ1
Final target minority/majority ratio (configurable).
Implementation
src/imgagn.py · train_imgagn

The generator produces weights \(T=\mathrm{softmax}(G(z))\) and features \(X_g = T X_{\min}\). The GCN discriminator combines two heads (real/fake and minority/majority) plus _mm_separation. Per epoch: noise sampling → synthetic build without gradients → discriminator training for \(d_{\text{steps}}\) minibatches → recompute \(X_g\) with gradients and optimise \(G\) minimising \(\mathcal{L}_G = \mathcal{L}_{rf} + \mathcal{L}_{mi} + \mathcal{L}_{di}\).

Optuna and evaluation

objective maximises validation F0.5 (precision-priority), searches hidden_channels, num_heads, dropout, num_layers and aggr1/aggr2. With GraphSMOTE it tunes smote_k, target_pos_ratio, smote_every_n_epochs and lambda_edge. Without GraphSMOTE it uses FocalLoss with focal_alpha and focal_gamma. Seed sampling can be re-sampled per epoch, fixed per trial, or load the full graph.

Evaluation: F1, AUC, AUPRC, MCC; threshold \(\tau\) chosen with pick_tau_fbeta; optional Platt calibration (AUTOCALIBRATE_PROBS); _hparams.json sidecar and graph hash (_calculate_graph_hash) for traceability.

Audited risks

Manual balancing leakage (mitigated: run_graphsmote restricts embeddings and minority pool to train_mask); BIDIRECCTION dependence in message diffusion; configurable accumulation_steps requires per-hardware tuning; using GraphSMOTE/ImGAGN disables class weights and validation metrics must be monitored.

Gantry-minute

Graph nodes are not gantries but (gantry, minute): each temporal bin is a distinct node. This models evolution without external recurrent networks.

Guard band. Separates the observed bin from the positive interval to prevent leakage: the model must not see the accident in its own features.

Balancing. GraphSMOTE interpolates in embedding space; ImGAGN synthesises via a GAN with a dual GCN discriminator.
