Chapter · Spatio-temporal graph

Graph Neural Network

Scope

Audit of the GNN pipeline (src/graph_builder_app.py, src/graph.py, src/gat_model.py, src/gnn_main.py, src/train_pretrain.py) with its balancing mechanisms (GraphSMOTE in src/graphsmote.py, ImGAGN in src/imgagn.py) and Optuna hyperparameter search.

Conceptual map

  1. Base data. Gantries, flows, and accidents are loaded and normalized through src/utils.py.
  2. Feature engineering. Snapshot and 5-minute flow features are generated from src/snapshot_pipeline.py and src/features.py.
  3. Feature selection. The UI supports manual/guided selection, persisted lists, and explicit control of pm.x dimensionality.
  4. Graph. The PyG object uses pm nodes, temporal, spatial, st_fwd relations, and edge attributes.
  5. Model. The base encoder is HeteroGAT; it can be combined with temporal heads and edge-aware variants.
  6. Balancing. GraphSMOTE adds nodes in embedding space and decodes them back to features; ImGAGN generates nodes adversarially.
  7. Evaluation. F1, F0.5, AUC, AUPRC, MCC, FAR, thresholds, and optional calibration are reported.
  8. Artifacts. Models, _hparams.json sidecars, augmented graphs, semantic hashes, and gnn_history.jsonl are persisted.

Graph data model

The Streamlit builder saves a torch_geometric.data.HeteroData graph. The primary node type is pm, interpreted as gantry-minute. Its central tensors are pm.x, pm.y, pm.is_accident_pm, train_mask, val_mask, test_mask, and sequence_mask. The .pt payload also persists metadata, edge_config, normalization, sequence_index, sequence_config, and graph_hash.

Main relations. All connect pm nodes, but they encode different mechanisms.
RelationDefinitionSemanticsAttributes
temporal\(P_{i,t}\to P_{i,t+1}\)Local persistence at the same gantry.\(\Delta x\) block; physical channels are zero-filled.
spatial\(P_{i,t}\leftrightarrow P_{i+1,t}\)Bidirectional spatial propagation at the same timestamp.\(\Delta x\), distance, gradients, shock-wave features, and congestion indicators recomputed per direction.
st_fwd\(P_{i,t}\to P_{i+1,t+1}\)Experimental space-time propagation.Gradients between the current gantry and next gantry in the next bin.

The first edge_attr block is the destination-source difference over selected delta columns. In Snapshot mode, the compact default tries to use speed_mean, speed_harmonic, flow_total, slow_pct, and speed_std when present; manual selections are preserved. The second block adds physical channels: distance, flow gradient, density gradient, speed gradient, shock-wave speed, shock indicator, and, in Snapshot mode, slow_pct gradient.

_build_raw_global_edge_features separates feature families. In classic mode it preserves \(q=\texttt{flujo_total}\), \(k=\texttt{densidad_total}\), \(v=\texttt{v_armonica}\), and \(\pi=\texttt{prop_pesados}\). In snapshot mode it uses \(q=\texttt{flow_total}\), \(v=\texttt{speed_harmonic}\) with fallback to speed_mean, \(k=q/\max(v,\epsilon)\) as a density proxy, \(\pi=\texttt{mix_cat_2}\) with fallback to flow_cat_2/flow_total, and \(s=\texttt{slow_pct}\) with zero fallback.

GNN architecture

The base model is src/gat_model.py::HeteroGAT: HeteroConv blocks with GATConvSaveAlpha, aggr1 and aggr2 aggregations, attention capture when XAI=1, batch-wise edge_attr validation, and optional gradient checkpointing to reduce memory through recomputation.

Variant registration is controlled by GNN_VARIANT and GNN_TEMPORAL_CACHE_STRATEGY in src/config.py, and materialized through _build_gnn_model, _build_temporal_head_for_variant, and _prime_temporal_cache_if_needed. The design separates spatial encoder, temporal head, and cache protocol.

Temporal cache

incremental keeps a batch-wise cache: cheaper, but more sampler-dependent. global_epoch performs one global forward per epoch with compute_epoch_embeddings; for scientific comparisons it is recommended because sequences share the same embedding reference.

Temporal heads reuse TemporalAggregator, update_cache(...), and _build_sequence_batch(...) to reconstruct \([B,L,D]\) tensors from sequence_rows. This allows switching among GRU, Transformer, or attention pooling without changing the train_minibatch contract or model forward signature.

For rare events, scientific comparison should prioritize PR-AUC/AUPRC, then ROC-AUC as a reference, Recall@target FAR/FPR for operational constraints, and MCC for robustness under extreme asymmetry. Variants persist gnn_variant and variant_tag in checkpoints, sidecars, and Optuna CSVs to prevent mixing incompatible architectures.

Training and optimization

The entry point is src/gnn_main.py::run_gat_training. The flow selects device with get_auto_device() (MPS, CUDA, or CPU), loads loaded_obj["data"], may run automatic ImGAGN, detects GraphSMOTE and existing synthetics, loads or runs HPO, builds the model with _build_gnn_model, trains z2x decoders if GraphSMOTE is active, attaches RelEdgeGen, selects CrossEntropy/FocalLoss, uses OneCycleLR, and runs mini-batches with early stopping.

Selection contract

Optuna keeps its configured objective_metric. Only final training uses validation loss for early stopping and BEST. This separates hyperparameter search, model selection, and operational reporting.

GraphSMOTE: modifications to the original architecture

Main module: src/graphsmote.py. Integration: src/gnn_main.py, src/train_pretrain.py, src/graph_builder_app.py, and src/config.py. Zhao, Zhang, and Wang formulate GraphSMOTE for transductive semi-supervised classification on a homogeneous graph \(G=\{V,A,F\}\), with one adjacency matrix \(A\), node features \(F\), a GraphSAGE extractor, embedding-space SMOTE, a bilinear edge generator, and loss \(L_{node}+\lambda L_{edge}\). The local pipeline requires re-specification because it operates on a temporal, relational gantry-minute graph with physical edge attributes, purged chronological splits, and extremely low positive prevalence.

Change 1 · From homogeneous graph to HeteroData

The original formulation operates on \(A\in\mathbb{R}^{n\times n}\). Here, typed pm\(\to\)pm relations are preserved: spatial, temporal, and st_fwd. Therefore RelEdgeGen does not learn one global \(S\), but one matrix \(S_r\) per relation.

\[ s_r(u,v)=\mathbf{z}_u^\top S_r\mathbf{z}_v,\qquad r=(\texttt{src},\texttt{rel},\texttt{dst}) \]
(6.7)
Rationale

A temporal edge and a downstream spatial edge encode different causal mechanisms; sharing \(S\) would mix semantics.

Change 2 · Heterogeneous and temporal extractor

GraphSMOTE is no longer tied to fixed GraphSAGE. It uses the active GNN variant: HeteroGAT, HeteroGATWithEdgeEncoder, HeteroEdgeAware, and GRU/Transformer/attention-pooling heads. Embeddings come from get_embeddings_minibatch or compute_train_embeddings, pass edge_attr_dict, and are node-wise \(\ell_2\)-normalized, giving k-NN and decoders a spherical geometry.

Change 3 · Training-only SMOTE

\[ \mathbf{z}_{syn}=(1-\alpha)\mathbf{z}_i+\alpha\mathbf{z}_j,\qquad \alpha\sim U(0,1) \]
(6.8)
Local restriction

Nodes \(i,j\) must belong to the train_mask minority pool.

The interpolation preserves the paper equation, but the eligible set is restricted to train_mask. compute_train_embeddings is used during training, and run_graphsmote also filters manual balancing. Validation and test never participate in k-NN or synthesis, preventing temporal leakage under purged chronological masks.

\[ n_{new}=\max\{0,\lceil r\,N_{train}\rceil-n_+\} \]
(6.9)
Variables
r
TARGET_POS_RATIO or target_pos_ratio.
Ntrain
Training nodes.
n+
Real positive training nodes.

Change 4 · \(z\to x\) decoders

The paper classifies directly in \(\tilde{H}\). The local pipeline requires a PyG graph with pm.x; therefore Z2XDecoders was added, one MLP per node type reconstructing features from synthetic embeddings.

\[ \mathbf{x}_{syn}=f_{\tau}(\mathbf{z}_{syn}) \]
(6.10)
Training

train_z2x_decoders uses SmoothL1/MSE, validation, early stopping, exclusion of is_synthetic, and minority mixup in \(z\) and \(x\).

Change 5 · Synthetic edge attributes

Original GraphSMOTE predicts only link existence; here every edge may carry edge_attr. Two paths were added: RelEdgeAttrDecoder, learning \([\mathbf{z}_{src}\Vert\mathbf{z}_{dst}]\mapsto\mathbf{e}_{src,dst}\) from real training edges, and a deterministic fallback \(\Delta x=x_{dst}-x_{src}\), restricted by delta_feature_idx when available and truncated/padded to the real dimensionality. _safe_clean_edges applies remove_self_loops and coalesce while preserving attributes if they remain aligned.

Change 6 · Top-K connectivity and direction

The paper proposes a global threshold \(\eta\) or soft edges over \(E_{v',u}\). For gantry-minute graphs this is quadratic and hard to audit. The implementation predicts top-K neighbors and restricts candidates through GRAPHSMOTE_CONECT: value 1 uses real candidates inside train_mask; value 0 uses one-hop neighbors of real training accidents. BIDIRECCTION=1 adds real\(\leftrightarrow\)synthetic edges; BIDIRECCTION=0 adds only real\(\to\)synthetic edges. The directed default avoids synthetic nodes injecting artificial evidence into real validation/test nodes.

Change 7 · Offline and online modes

augment_graph_offline_once creates one augmented graph; refresh_synthetics_online always returns to the real base graph and regenerates every SMOTE_EVERY_N_EPOCHS; none disables augmentation. Online mode replaces previous synthetics instead of accumulating them, avoiding uncontrolled growth, distribution drift, and training on samples produced by older model states.

Change 8 · Loss, class weights, and diagnostics

train_minibatch trains RelEdgeGen with real positive edges from the batch and sampled negatives. pretrain_edge_generator uses BCE and reports AUC/AP by relation. When GraphSMOTE is active, class weights and focal_alpha are disabled to avoid correcting imbalance twice; without GraphSMOTE, CrossEntropyLoss uses tempered weights \(\sqrt{1/n_c}\), more stable than \(1/n_c\) under near-zero prevalence.

Change 9 · Traceability

Synthetics are appended to pm.x and pm.y, added only to train_mask, excluded from val_mask and test_mask, marked with is_synthetic=True, and marked is_accident_pm=False. The last flag separates a positive synthetic training sample from an observed crash. The pipeline persists z2x decoders, edge_gen_auc.json, augmented graphs, hparams tagged with _GraphSMOTE, graph_hash, and synthetic counts in TensorBoard/Streamlit.

ImGAGN: adversarial generation

Module: src/imgagn.py. ImGAGN homogenizes HeteroData toward target pm, preserving edge_attr and delta_feature_idx when present, and generates synthetic nodes as convex combinations of minority training nodes.

\[ \lambda_1=\frac{n_{\min}+n_g}{n_{\mathrm{maj}}} \quad\Rightarrow\quad n_g=\max(0,\lambda_1 n_{\mathrm{maj}}-n_{\min}) \]
(6.11)
Scale control

max_new_nodes caps \(n_g\) to avoid OOM.

ImGAGNGenerator receives noise \(\mathbf{z}\sim\mathcal{N}(0,I)\), produces logits over minority nodes, computes \(T=\mathrm{softmax}(G(z))\), and synthetic features \(X_g=TX_{\min}\). Edges are created by top-K links to real minority nodes. ImGAGNDiscriminator combines a real/fake head, a minority/majority head, and _mm_separation to push minority and majority means apart.

Each epoch samples noise, builds synthetics without gradients, trains the discriminator for d_steps mini-batches, recomputes \(X_g\) with gradients, and optimizes the generator.

\[ \mathcal{L}_G=\mathcal{L}_{rf}+\mathcal{L}_{mi}+\mathcal{L}_{di} \]
(6.12)
Terms
ℒrf
Pushes synthetics toward real.
ℒmi
Pushes synthetics toward minority.
ℒdi
Pulls embeddings toward minority centroids.

Scalability uses NeighborLoader when available and falls back to full-batch otherwise. The final rebuilt graph returns x_aug, edge_index_aug, edge_attr_aug, and the generated-node block.

Optuna, evaluation, and artifacts

src/gnn_main.py::objective maximizes validation F0.5, prioritizing precision. The space includes hidden_channels, num_heads, dropout, num_layers, aggr1/aggr2, and Adam/AdamW/RAdam optimizers. With GraphSMOTE it adds smote_k, target_pos_ratio, smote_every_n_epochs, and lambda_edge; without GraphSMOTE it searches focal_alpha and focal_gamma.

  • Seed sampling. It may resample seeds per epoch, fix one subset per trial, or load the full graph into memory with sample_train_nodes=0 and sample_val_nodes=0.
  • Evaluation. test computes loss when a criterion is supplied, plus F1, AUC, AUPRC, MCC, and confusion matrix.
  • Threshold. pick_tau_fbeta searches \(\tau\) on validation.
  • Calibration. AUTOCALIBRATE_PROBS enables Platt scaling.
  • Persistence. gat_model_BEST*.pt, GraphSMOTE_embeddings_model*.pt, _hparams.json, hashes, and split metadata are saved.

Technical audit

Implemented strengths
  • Purged temporal split from the full feature timeline, not from positive timestamps.
  • Normalization estimated only on purged training nodes.
  • Physical edge channels computed from raw traffic magnitudes before z-scoring.
  • Payloads with self-contained metadata and semantic hash.
  • GraphSMOTE uses train embeddings and preserves synthetic-node traceability.
  • NeighborLoader, cleaning/coalesce, and sidecars reduce operational risk and improve reproducibility.
  • BEST checkpoint selected by validation loss, separated from threshold-dependent metrics.
Critical risks
  • Legacy graphs without label_lookahead_minutes use zero embargo on re-split; rebuild them for strict evaluation.
  • Short temporal ranges may empty train/val/test under strict embargo.
  • The strict contract documented here applies to the Streamlit builder; src/graph.py should be audited separately if used as a paper-grade generator.
  • BIDIRECCTION changes message diffusion and must be reported in comparisons.
  • val_loss is comparable only when split, criterion, weights, variant, and graph_hash are fixed.

Recommendations and references

Gantry-minute

Graph nodes are not gantries but (gantry, minute): each temporal bin is a distinct node. This models evolution without external recurrent networks.

Embargo. The purged split uses label lookahead to prevent validation/test from contaminating train.

Balancing. GraphSMOTE interpolates in embeddings and returns to pm.x; ImGAGN uses generator/discriminator training.

Selection. The final BEST checkpoint is decided by val_loss, not F1/F0.5.
