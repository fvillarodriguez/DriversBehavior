Chapter · Batch vs adaptive recalibration

Drift detection

Scope and paper alignment

The module src/drift_detection_app.py replicates the paper Evaluating recalibration strategies for real-time crash prediction: adaptive drift detection vs. cumulative retraining. It concentrates dataset preparation, yearly batch strategies, ADWIN/ARF/KSWIN adaptive strategies, checkpoint persistence, tuning cache and SMOTE artefacts, with outputs aligned to Appendix A.6–A.9 and Figure 7.

The paper's locked configuration fixes PAPER_TIME_SPAN = 2018-01-01 to 2024-09-30 and a gantry corridor DRIFT_FOCUS_PORTICOS = {11,12,14,15}, with segments 15→14, 14→12 and 12→11.

UI map

  • Events: accident loading and mapping.
  • Feature engineering: build or load features; export DuckDB with raw_features and clean_features.
  • Feature Selection: correlation filter and Random Forest ranking.
  • Experiments: runs run_recalibration_experiments() with preview, resume and clean start.
  • Neural drift: tab delegated to src/Neural_drift_app.py.

Feature engineering

With \(\Delta=5\) min and \(b(\tau)=\lfloor\tau/\Delta\rfloor\Delta\), the corridor's full predictor space yields 260 variables:

  • 96 per gantry and category (4 base metrics + 4 deltas, 4 gantries × 3 categories).
  • 8 compositional per gantry (ft_motorcycle_*, ft_heavy_*).
  • 72 per segment and category (5 base + 3 deltas).
  • 21 global per segment (4 base + 3 deltas).
  • 63 per origin lane (4 base + 3 deltas).

Segment matching and spatial speed

An upstream/downstream pair is accepted if it shares the plate, category matches, the downstream pass is later, and travel time falls within \( \tau_s=\max(30, 60 d_s/20) \) minutes. For each match \(m\):

\[ \mathrm{TT}_m = \tau^{\text{end}}_m - \tau^{\text{start}}_m,\quad \mathrm{SegVel}_m = \frac{d_s}{\mathrm{TT}_m/1\,\text{h}},\quad \mathrm{LC}_m = \mathbf{1}\{\ell^{\text{start}}_m\neq\ell^{\text{end}}_m\} \]
(4.2)

Selection and experimental design

Selection combines a correlation filter with RF ranking. Strategies are static, period_aligned, cumulative, adaptive_adwin, adaptive_arf and adaptive_kswin; batch models are XGBoost, AdaBoost, Random Forest and NNet; online variants are ARFmoderate, ARFmaj, ARFfast, KSWINpaper and KSWINseasonal.

ADWIN

The detector keeps an error window \(W = W_0\cup W_1\). It declares drift if \(|\mu_0-\mu_1| > \epsilon\), with

\[ m=\left(\tfrac{1}{n_0}+\tfrac{1}{n_1}\right)^{-1},\quad \delta'=\tfrac{\delta}{n},\quad \epsilon = \sqrt{\tfrac{1}{2m}\log\tfrac{4n}{\delta}} \]
(4.6)
Variables
W0, W1
Compared sub-windows (older vs newer).
m
Effective harmonic size.
δ, δ'
Global and per-point confidence (Bonferroni correction).
ε
Hoeffding bound to declare a significant difference.
Implementation
src/drift_detection_app.py · SimpleADWIN._hoeffding_cut_threshold

After a cut, the model is recalibrated using the most recent \(|W_1|\) observations if minimums are met.

ARF and KSWIN

ARF is genuinely online: \(s_t = f_{t-1}(x_t)\), \(f_t = \mathcal{U}(f_{t-1}, x_t, y_t)\). It does not duplicate per balance_mode.

KSWIN monitors the top-k columns with \(\alpha=10^{-4}\), window_size=300, stat_size=30. It triggers drift if \(|F_t|\ge\texttt{vote_threshold}\); recalibrates with a temporal window \(\mathcal{R}_t=\{i:t_i\ge t-D\}\).

NNet · stability policy

NNet trains with per-fold StandardScaler (avoids temporal leakage), solver=adam, early_stopping=True, validation_fraction=0.1, n_iter_no_change=20, tol=1e-4. The maxit grid is \(\{300,500\}\) in fast mode and \(\{300,500,800\}\) in full mode. A non-converged fold is marked invalid; the final refit retries once with doubled max_iter (cap 1000) and, if it still fails, the block is skipped.

Persistence and expected results

The central manifest tracks progress, completed blocks, skipped blocks and errors. With continue_on_block_error=True, failed blocks are marked skipped_failed and the run continues; global tuning remains fail-fast. NNet cache compatibility depends on NNET_TRAINING_POLICY_VERSION.

Consolidated outputs include yearly_results, adaptive_results, summary, appendix_tables (A.6–A.9) and appendix_tables_mean, average_roc (101-point FPR grid), and run_manifest + execution_log.

Neural drift

The submodule src/Neural_drift_app.py implements online backtesting. The experimental unit is \( (\texttt{model}, \texttt{strategy}, \texttt{balance\_mode}) \), with three predictors (XGBoost, Torch MLP, Torch MLP + Attention), four strategies (fixed, recalibration, fine_tuning, retrain) and four drift channels (input, score, error, embedding).

Augmentation and windows

Deltas, rate, rolling stats (window 3) and regime variables (shock_speed_drop, shock_density_jump, relative_congestion, etc.) are added. The window has length \(L=\texttt{lookback\_steps}\) and the future objective is \( \tilde y_t = \max\{y_t,\dots,y_{t+H-1}\} \). The split admits fractions or fixed_dates (base 2018, stream 2019+).

Adaptation strategies

  • fixed: the predictor never changes; severity is still recorded as a negative control.
  • recalibration: recomputes scores, retrains the Platt calibrator, re-optimises the threshold with \(F_\beta\) and rebuilds reference statistics.
  • fine_tuning: Torch lowers LR and shrinks the budget; XGBoost selects an adaptive sub-window and optimises \(\eta_t = \eta_{\text{base}}[1+(\texttt{eta\_multiplier\_max}-1)\mathrm{severity\_intensity}_t]\) and recency weights.
  • retrain: builds a hybrid dataset \(\mathcal{H}_t = \text{history}\cup W_t\) and retrains from scratch.

Experimental sweep

src/neural_drift_experiments.py fixes the protocol (base 2018, dev 2019–2022, holdout 2023–2024), seeds (42, 7, 123) and Optuna phases for adwin and neural. The ranking score aggregates by calendar month:

\[ \mathrm{score} = \mathrm{median\_month}(\mathrm{PR\text{-}AUC}) - 0.05\cdot\mathrm{action\_cost} - 0.10\cdot\mathrm{stability\_penalty} \]
(4.9)
Variables
median_month
Monthly median of PR-AUC over the holdout.
action_cost
Aggregate cost of retrains / fine-tunings.
stability_penalty
Penalty for the model's temporal variance.
Implementation

Drift

The paper compares batch recalibration (yearly, calendar-driven) with adaptive detection (ADWIN, ARF, KSWIN). The operational question: when does retraining pay off?

Lead time. 5 minutes: features at bin t must anticipate accidents at t+1.

SMOTE. Train folds only. Never on stream or test.

Severity. Combination of four channels (input, score, error, embedding) under an OR rule against the threshold.
