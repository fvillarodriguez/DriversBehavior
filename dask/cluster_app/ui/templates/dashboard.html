Funciones de la app

Descripcion operativa de todo lo que este panel, la UI principal, la API y el CLI permiten hacer en el cluster local.

Usuarios y sesiones

  • Registro y login local: crea o reutiliza usuarios por nombre y email, emite un token firmado y guarda la sesion en el navegador para autorizar acciones sensibles.
  • Actividad de usuarios: registra sesiones vistas en los ultimos minutos para mostrar quienes estan conectados desde la pantalla principal.
  • Administracion de usuarios: lista usuarios registrados y permite borrar cuentas cuando no tienen jobs activos o en cola.

Jobs y cola

  • Explorador de carpetas: navega el filesystem local, filtra carpetas y scripts Python, y ayuda a escoger el entrypoint correcto dentro del folder del job.
  • Envio de jobs: empaqueta una carpeta, argumentos y entrypoint; crea un workspace aislado por job y deja el trabajo listo para la cola.
  • Cola con un activo global: mantiene un solo job corriendo a la vez, reintenta fallas segun configuracion y avisa si un job largo bloquea la cola.
  • Dependencias y checkpoints: reutiliza entornos virtuales por hash de requirements y ofrece helpers para guardar o recuperar checkpoints del job.
  • Detalle, logs y cancelacion: muestra estado, duracion, espera en cola, scheduler usado, stdout/stderr y datos de fallo; tambien permite detener jobs activos.

Dask y recursos

  • Scheduler administrado: arranca, detiene e inspecciona el scheduler Dask local, o usa un scheduler elegido desde otro nodo cuando corresponde.
  • Workers administrados: conecta workers al scheduler activo con TLS, limites de memoria y recursos detectados por hardware.
  • Dashboard de Dask: expone el enlace al panel nativo de Dask cuando el scheduler esta online y el puerto es alcanzable.
  • Recursos por nodo: resume CPU, RAM, GPU/backends, host, estado y ultima presencia de cada nodo registrado.

Nodos y descubrimiento

  • Presencia mDNS: publica el nodo local y escanea la LAN usando el servicio configurado para descubrir otros nodos automaticamente.
  • Fallback por IP: permite agregar nodos remotos manualmente cuando multicast o discovery no estan disponibles.
  • Pruebas de conectividad: valida alcance TCP de cada nodo y reporta errores de red, CPU y presencia de GPU.
  • Limpieza y revocacion: marca nodos viejos como offline, elimina nodos inactivos o revocados y conserva los nodos online.

Seguridad y configuracion

  • TLS obligatorio: genera una CA interna, certificados por nodo y variables de entorno para que los procesos Dask hablen cifrado.
  • Tokens firmados: usa HMAC para sesiones web y pairing de nodos, con secretos locales persistidos en el state dir.
  • Config YAML/JSON: carga configuracion desde archivo, expande paths de usuario y crea directorios de estado, workspaces, envs, logs y certificados.
  • Backup de CA: incluye soporte para respaldar y restaurar la CA interna con cifrado Fernet.

Operacion y herramientas

  • CLI cluster-app: inicializa config, arranca la web, ejecuta agente, diagnostica red, envia jobs, muestra estado y genera planes de servicio.
  • Diagnosticos: prueba puertos, host local y disponibilidad del scheduler para detectar bloqueos de red o configuracion.
  • Planes de firewall y servicio: calcula comandos para abrir puertos y preparar LaunchDaemon o servicio de Windows sin aplicarlos automaticamente.
  • Eventos en tiempo real: envia por WebSocket el estado de cola, job activo y nodos; las metricas HTTP alimentan este Dashboard cada pocos segundos.
  • Helpers para notebooks: ofrece un helper de conexion para notebooks que necesitan usar el scheduler Dask administrado por la app.
