\section{Scope and methodology}
This report documents and audits the GNN pipeline implemented in the repository, focusing on:
\begin{itemize}[leftmargin=*]
  \item The tab-by-tab workflow of the Streamlit application (\texttt{src/graph\_builder\_app.py}).
  \item Graph construction, the GNN model, training, and evaluation (\texttt{src/graph.py}, \texttt{src/gat\_model.py}, \texttt{src/gnn\_main.py}, \texttt{src/train\_pretrain.py}).
  \item Class balancing mechanisms: GraphSMOTE and ImGAGN (\texttt{src/graphsmote.py}, \texttt{src/imgagn.py}).
  \item Hyperparameter optimization (Optuna) and metric tracking.
\end{itemize}
The audit includes best-practice checks, information leakage risks, memory/compute considerations, and consistency with configuration options in \texttt{src/config.py}.

\section{Overall pipeline map}
\textbf{Conceptual summary:}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Base data}: gantries, flows, and accidents (\texttt{src/utils.py}).
  \item \textbf{Feature engineering}: snapshot/flow processing (\texttt{src/snapshot\_pipeline.py}, \texttt{src/features.py}).
  \item \textbf{Feature selection}: manual/UI-guided selection and persistence.
  \item \textbf{Graph}: \texttt{pm} nodes, \texttt{temporal/spatial/st\_fwd} edges, and edge attributes (\texttt{src/graph.py}).
  \item \textbf{Training}: HeteroGAT + optional TemporalAggregator (\texttt{src/gat\_model.py}, \texttt{src/temporal\_head.py}).
  \item \textbf{Balancing}: GraphSMOTE (embedding-space + z\textrm{\textrightarrow}x + edge generation) and/or ImGAGN (adversarial) (\texttt{src/graphsmote.py}, \texttt{src/imgagn.py}).
  \item \textbf{Evaluation}: metrics (F1, AUC, AUPRC, MCC), thresholds, and calibration (\texttt{src/gnn\_main.py}).
  \item \textbf{Artifacts}: models, hparams JSON files, augmented graphs, and run history (\texttt{Resultados/}, \texttt{gnn\_history.jsonl}).
\end{enumerate}

\section{Graph data model}
\label{sec:grafo}
\textbf{Nodes}: \texttt{pm} (gantry-minute).\\
\textbf{Targets}: \texttt{pm.y} (binary label), \texttt{pm.is\_accident\_pm} (direct accident flag).\\
\textbf{Masks}: \texttt{train\_mask/val\_mask/test\_mask/sequence\_mask}.

\subsection{Edges and attributes}
\textbf{Main edges} (\texttt{src/graph.py}):
\begin{itemize}[leftmargin=*]
  \item \texttt{temporal}: $P_{i,t} \to P_{i,t+1}$ (same location, next time).
  \item \texttt{spatial}: $P_{i,t} \to P_{i+1,t}$ (next gantry, same time).
  \item \texttt{st\_fwd} (optional): $P_{i,t} \to P_{i+1,t+1}$.
  \item \texttt{spatial\_back} (optional): reverse of \texttt{spatial}.
\end{itemize}
\textbf{Edge attributes}: feature differences between destination and source ($\Delta x$) plus extra channels for \texttt{spatial} edges (gradients, shock, distance). For \texttt{temporal} and \texttt{st\_fwd}, extra channels are set to zero to keep dimensions aligned.

\subsection{Temporal labeling}
\textbf{Time cutoffs}: defined from chronologically sorted accidents (\texttt{\_compute\_time\_cutoffs}).\\
\textbf{Masks}: assigned by minute-level timestamps.\\
\textbf{SequenceIndex}: temporal sequences with guard band and future horizon (\texttt{src/snapshot\_sequences.py}).

\section{GNN model architecture}
\textbf{Base model}: \texttt{src/gat\_model.py::HeteroGAT}.
\begin{itemize}[leftmargin=*]
  \item \textbf{Layers}: \texttt{num\_layers} blocks of \texttt{HeteroConv} with \texttt{GATConvSaveAlpha}.
  \item \textbf{Aggregation}: \texttt{aggr1} on first layer, \texttt{aggr2} on subsequent layers.
  \item \textbf{Attentions}: captured when \texttt{XAI=1}, used for $L2$ regularization.
  \item \textbf{Edge attributes}: validated per batch; missing/misaligned tensors are zero-padded.
  \item \textbf{Checkpointing}: \texttt{use\_checkpointing} reduces memory usage via recomputation.
\end{itemize}

\subsection{Temporal head (optional)}
\textbf{Class}: \texttt{src/temporal\_head.py::TemporalAggregator}.\\
\textbf{Idea}: GRU over recent embedding sequences; keeps a cache for nodes not present in the current batch, avoiding gradient leakage.

\subsection{GNN variant registry (encoder + temporal + edge processing)}
\label{sec:gnn_variants}
The pipeline now includes a \textbf{variant registry} controlled from
\texttt{src/config.py} (\texttt{GNN\_VARIANT}, \texttt{GNN\_TEMPORAL\_CACHE\_STRATEGY})
and instantiated in \texttt{src/gnn\_main.py} through
\texttt{\_build\_gnn\_model}, \texttt{\_build\_temporal\_head\_for\_variant}, and
\texttt{\_prime\_temporal\_cache\_if\_needed}. In addition, the UI in
\texttt{src/graph\_builder\_app.py} exposes a condensed guide in the
\emph{Network}, \emph{Training}, \emph{Optuna}, and \emph{Evaluation} tabs.
The design separates:
\begin{itemize}[leftmargin=*]
  \item \textbf{Spatial encoder}: base heterogeneous GAT, GAT with edge encoder, or edge-aware alternative.
  \item \textbf{Temporal head}: snapshot-only (no sequence), GRU, temporal Transformer, or attention pooling.
  \item \textbf{Cache protocol}: batch-wise \texttt{incremental} caching or \texttt{global\_epoch} (one global encoder pass per epoch for consistent sequences).
\end{itemize}

\subsubsection{General comparability idea}
All variants share the same \texttt{SequenceIndex} (built in
\texttt{src/snapshot\_sequences.py} using \texttt{sequence\_rows}/\texttt{target\_rows}),
the same graph, and the same temporal splits. This enables architectural comparisons
without changing the target definition or prediction horizon.

\paragraph{``5 minutes before'' labeling}
The labeling logic uses:
\[
\text{positive interval} = (t+\gamma,\; t+\gamma+H]
\]
where \(\gamma\) is \texttt{GUARD\_BAND\_MINUTES} and \(H\) is \texttt{HORIZON\_MINUTES}.
For a strict ``5 minutes before'' setup, the recommended configuration is:
\begin{itemize}[leftmargin=*]
  \item \texttt{GUARD\_BAND\_MINUTES = 5}
  \item \texttt{HORIZON\_MINUTES = 5} (or 10--20 for a risk window)
\end{itemize}
in \texttt{src/config.py}.

\subsubsection{Implemented variants}
\textbf{Implementation}: \texttt{src/gat\_model.py}, \texttt{src/temporal\_head.py},
\texttt{src/temporal\_heads.py}, \texttt{src/gnn\_main.py}.\\
\textbf{Selection}: via the \texttt{GNN\_VARIANT} string (normalized in
\texttt{src/gnn\_main.py::\_normalize\_gnn\_variant}).

\begin{enumerate}[leftmargin=*]
  \item \textbf{\texttt{gat\_snapshot}} (baseline): \texttt{HeteroGAT} without a temporal head. Classification uses the current snapshot embedding.
  \item \textbf{\texttt{gat\_gru}}: \texttt{HeteroGAT} + \texttt{TemporalGRUHead} (\texttt{src/temporal\_heads.py}).
  \item \textbf{\texttt{gat\_transformer}}: \texttt{HeteroGAT} + \texttt{TemporalTransformerHead} (self-attention with learnable positional embedding).
  \item \textbf{\texttt{gat\_attnpool}}: \texttt{HeteroGAT} + \texttt{TemporalAttnPoolHead} (lightweight, low-cost ablation).
  \item \textbf{\texttt{gat\_edge\_mlp}}: \texttt{HeteroGATWithEdgeEncoder} (per-edge-type MLP over \texttt{edge\_attr}) without a temporal head.
  \item \textbf{\texttt{gat\_edge\_mlp\_gru}} and \textbf{\texttt{gat\_edge\_mlp\_transformer}}: combine edge encoding with temporal heads.
  \item \textbf{\texttt{gnn\_edge\_aware}}: \texttt{HeteroEdgeAware} (built on \texttt{TransformerConv}) without a temporal head.
  \item \textbf{\texttt{gnn\_edge\_aware\_gru}} and \textbf{\texttt{gnn\_edge\_aware\_transformer}}: edge-aware variants with temporal modeling.
\end{enumerate}

\subsubsection{Edge attribute encoding (\texttt{edge\_attr})}
The \texttt{HeteroGATWithEdgeEncoder} variant adds an edge MLP
(\texttt{EdgeAttrEncoder}) before graph attention. Motivation:
\begin{itemize}[leftmargin=*]
  \item \(\Delta x\) channels may have heterogeneous scales;
  \item a learned mapping can induce a more stable geometry for attention;
  \item it enables isolated analysis of ``better \texttt{edge\_attr}'' vs. ``better temporal head''.
\end{itemize}

\subsubsection{Temporal heads and sequence assembly}
Temporal heads reuse the \texttt{TemporalAggregator} infrastructure:
\begin{itemize}[leftmargin=*]
  \item \texttt{update\_cache(...)} for global or partial embedding caching.
  \item \texttt{\_build\_sequence\_batch(...)} to reconstruct \([B, L, D]\) tensors using \texttt{sequence\_rows}.
\end{itemize}
This allows changing the temporal operator (GRU/Transformer/attention pooling)
without changing the training contract in \texttt{src/train\_pretrain.py} or the
model \texttt{forward} signature.

\subsubsection{Temporal cache strategies (critical implementation point)}
\begin{itemize}[leftmargin=*]
  \item \textbf{\texttt{incremental}}: batch-wise cache updates (historical behavior, lower cost, more sampler-dependent).
  \item \textbf{\texttt{global\_epoch}}: epoch-level priming using a global encoder pass (\texttt{compute\_epoch\_embeddings}), then train/eval consume a consistent cache.
\end{itemize}
\textbf{Recommendation for paper-grade comparisons}: prefer \texttt{global\_epoch}
so temporal sequences are aligned to the same embedding reference within each epoch.

\subsubsection{Recommended experiment matrix}
\begin{enumerate}[leftmargin=*]
  \item \texttt{gat\_snapshot} (spatial baseline)
  \item \texttt{gat\_gru}
  \item \texttt{gat\_transformer}
  \item \texttt{gat\_edge\_mlp\_gru}
  \item \texttt{gnn\_edge\_aware\_gru} (or \texttt{gnn\_edge\_aware\_transformer})
\end{enumerate}
Keep seed, temporal split, \texttt{SequenceIndex}, and evaluation protocol fixed.

\subsubsection{Metrics for rare events}
For scientific and operational comparison, prioritize:
\begin{itemize}[leftmargin=*]
  \item \textbf{PR-AUC / AUPRC}: primary metric under severe imbalance.
  \item \textbf{ROC-AUC}: secondary reference.
  \item \textbf{Recall at target FAR/FPR}: useful under operational false-alarm constraints.
  \item \textbf{MCC}: robust under strong class asymmetry.
\end{itemize}

\subsubsection{Variant traceability}
Training and HPO persist \texttt{gnn\_variant} and \texttt{variant\_tag}
in hyperparameter sidecars, checkpoints, and structured logs
(\texttt{Resultados/gat\_model\_BEST*.pt}, \texttt{\_hparams.json}, Optuna CSVs).
This prevents mixing checkpoints from incompatible architectures.

\section{Training and optimization}
\textbf{Entry point}: \texttt{src/gnn\_main.py::run\_gat\_training}.

\subsection{Training flow}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Device}: \texttt{get\_auto\_device()} (MPS $>$ CUDA $>$ CPU).
  \item \textbf{Data load}: \texttt{loaded\_obj['data']}.
  \item \textbf{Automatic ImGAGN} (if \texttt{AUTO\_IMGAGN\_PRETRAIN=1}).
  \item \textbf{GraphSMOTE}: selected by user/flag with detection of existing synthetic nodes.
  \item \textbf{HPO}: load \texttt{optuna\_hyperparams\_*.csv} or run a new search.
  \item \textbf{Model}: the \texttt{\_build\_gnn\_model} factory selects the encoder/temporal head according to \texttt{gnn\_variant} and attaches a temporal head when applicable.
  \item \textbf{z\textrightarrow x decoders}: train if GraphSMOTE is active (\texttt{train\_z2x\_decoders}).
  \item \textbf{Edge generator}: \texttt{RelEdgeGen} for edge reconstruction and synthetic edge creation.
  \item \textbf{Loss}: \texttt{CrossEntropy} or \texttt{FocalLoss} (with or without class weights).
  \item \textbf{Scheduler}: \texttt{OneCycleLR}.
  \item \textbf{Loop}: mini-batch training, validation, early stopping, and best-model checkpointing.
\end{enumerate}

\subsection{Mini-batch training and regularization}
\textbf{Function}: \texttt{src/train\_pretrain.py::train\_minibatch}.
\begin{itemize}[leftmargin=*]
  \item Classification on \texttt{pm} nodes (first \texttt{batch\_size} elements from \texttt{NeighborLoader}).
  \item Total loss:
  \[
  \mathcal{L} = \mathcal{L}_{cls} + \lambda_{edge}\,\mathcal{L}_{edge} + \lambda_{att}\,\mathcal{L}_{att}.
  \]
  \item \textbf{\(\mathcal{L}_{edge}\)}: edge reconstruction with negative sampling (when \texttt{edge\_gen} is active).
  \item \textbf{\(\mathcal{L}_{att}\)}: $L2$ attention regularization when \texttt{XAI=1}.
  \item Gradient accumulation (\texttt{accumulation\_steps=2}) and \texttt{grad\_clip}.
  \item AMP support (CUDA only).
\end{itemize}

\section{GraphSMOTE: synthetic node and edge generation}
\label{sec:graphsmote}
\textbf{Module}: \texttt{src/graphsmote.py}.\\
\textbf{Principle}: synthesize nodes in embedding space and decode them into feature space.

\subsection{Step 1: embeddings}
\begin{itemize}[leftmargin=*]
  \item \texttt{get\_embeddings\_minibatch} (offline UI balancing) or \texttt{compute\_train\_embeddings} (training-time, leakage-safe).
  \item Node-wise $\ell_2$ normalization.
\end{itemize}

\subsection{Step 2: SMOTE in embedding space}
SMOTE is applied to the minority set:
\[
\mathbf{z}_{syn} = (1-\alpha)\,\mathbf{z}_i + \alpha\,\mathbf{z}_j,\quad \alpha \sim U(0,1).
\]
\begin{itemize}[leftmargin=*]
  \item k-NN over minority embeddings (CPU cache or GPU when feasible).
  \item Key parameters: \texttt{GRAPHSMOTE\_K}, \texttt{smote\_k}, \texttt{random\_state}.
\end{itemize}

\subsection{Step 3: z\textrightarrow x decoders}
\textbf{Class}: \texttt{Z2XDecoders}.\\
\textbf{Training}: \texttt{train\_z2x\_decoders} with SmoothL1/MSE, early stopping, and validation.
\begin{itemize}[leftmargin=*]
  \item One MLP per node type: $\mathbf{x}\_{syn} = f_{ntype}(\mathbf{z}\_{syn})$.
  \item Respect \texttt{train/val\_mask} and avoid out-of-split nodes when masks are available.
\end{itemize}

\subsection{Step 4: node insertion}
\begin{itemize}[leftmargin=*]
  \item Concatenate synthetic \texttt{x} and \texttt{y} into \texttt{pm.x} and \texttt{pm.y}.
  \item Update \texttt{train/val/test\_mask} (new nodes go to train by default).
  \item Create/update \texttt{is\_synthetic} and \texttt{is\_accident\_pm}.
\end{itemize}

\subsection{Step 5: synthetic edge generation}
\textbf{Generator}: \texttt{RelEdgeGen} (relation-specific parameters).\\
\textbf{Real-node candidates}:
\begin{itemize}[leftmargin=*]
  \item \texttt{GRAPHSMOTE\_CONECT=1}: top-K within \texttt{train\_mask}.
  \item \texttt{GRAPHSMOTE\_CONECT=0}: one-hop neighbors of real accident nodes.
\end{itemize}
\textbf{Direction}:
\begin{itemize}[leftmargin=*]
  \item \texttt{BIDIRECCTION=1}: real $\leftrightarrow$ synthetic.
  \item \texttt{BIDIRECCTION=0}: real $\to$ synthetic only.
\end{itemize}
\textbf{Edge attributes}: computed as destination-source $\Delta x$ (with \texttt{delta\_feature\_idx} when available) and aligned to existing edge-attribute dimensionality.

\subsection{Operation modes}
\begin{itemize}[leftmargin=*]
  \item \textbf{Offline}: \texttt{augment\_graph\_offline\_once} augments once and trains on the augmented graph.
  \item \textbf{Online}: \texttt{refresh\_synthetics\_online} regenerates nodes every \texttt{SMOTE\_EVERY\_N\_EPOCHS}.
  \item \textbf{None}: no augmentation.
\end{itemize}

\section{ImGAGN: adversarial generation}
\label{sec:imgagn}
\textbf{Module}: \texttt{src/imgagn.py}.\\
\textbf{Core idea}: generate synthetic nodes as convex combinations of minority \emph{training} nodes and train an adversarial discriminator.

\subsection{Step 1: homogenization}
\texttt{to\_homogeneous\_if\_needed} converts \texttt{HeteroData} into a homogeneous graph (target \texttt{pm}), preserving \texttt{edge\_attr} and \texttt{delta\_feature\_idx} when present.

\subsection{Step 2: define synthetic node count}
\begin{align*}
\lambda_1 &= \frac{n_{min} + n_g}{n_{maj}} \\
\Rightarrow n_g &= \max\bigl(0,\, \lambda_1 n_{maj} - n_{min}\bigr)
\end{align*}
The value is capped by \texttt{max\_new\_nodes} to avoid OOM conditions.

\subsection{Step 3: generator}
\textbf{Class}: \texttt{ImGAGNGenerator}.\\
\begin{itemize}[leftmargin=*]
  \item Input: noise $\mathbf{z} \sim \mathcal{N}(0, I)$.
  \item Output: logits over minority training nodes.
  \item Weights $T = \mathrm{softmax}(G(z))$ and synthetic features $X_g = T X_{min}$.
  \item Edges: top-K links to real minority nodes according to $T$.
\end{itemize}

\subsection{Step 4: discriminator}
\textbf{Class}: \texttt{ImGAGNDiscriminator} (GCN + two heads).
\begin{itemize}[leftmargin=*]
  \item \textbf{Real/fake head} (BCE).
  \item \textbf{Minority/majority head} (BCE).
  \item Separation term \texttt{\_mm\_separation} to push minority and majority means apart.
\end{itemize}

\subsection{Step 5: adversarial training}
For each \texttt{epoch}:
\begin{enumerate}[leftmargin=*]
  \item Sample noise and build synthetic nodes (without gradients).
  \item Build augmented graph and train D for \texttt{d\_steps} mini-batches.
  \item Recompute $X_g$ with gradients and optimize G using:
  \[
  \mathcal{L}_G = \mathcal{L}_{rf} + \mathcal{L}_{mi} + \mathcal{L}_{di},
  \]
  where $\mathcal{L}_{rf}$ pushes toward \emph{real}, $\mathcal{L}_{mi}$ pushes toward \emph{minority}, and $\mathcal{L}_{di}$ pulls embeddings toward minority centroids.
\end{enumerate}
\textbf{Scalability}: uses \texttt{NeighborLoader} when available; otherwise falls back to full-batch.

\subsection{Step 6: final graph}
The augmented graph is rebuilt with the final generator, returning:
\texttt{x\_aug}, \texttt{edge\_index\_aug}, \texttt{edge\_attr\_aug}, and the generated-node block.

\section{Optuna (hyperparameter optimization)}
\label{sec:optuna}
\textbf{Function}: \texttt{src/gnn\_main.py::objective}.
\begin{itemize}[leftmargin=*]
  \item Objective: maximize validation F0.5 (precision-oriented).
  \item Search space: \texttt{hidden\_channels}, \texttt{num\_heads}, \texttt{dropout}, \texttt{num\_layers}, \texttt{aggr1/aggr2}.
  \item Optimizers: Adam/AdamW/RAdam (configurable).
  \item With GraphSMOTE: search \texttt{smote\_k}, \texttt{target\_pos\_ratio}, \texttt{smote\_every\_n\_epochs}, \texttt{lambda\_edge}.
  \item Without GraphSMOTE: \texttt{FocalLoss} with \texttt{focal\_alpha}, \texttt{focal\_gamma}.
\end{itemize}
\textbf{Seed sampling options (train/val)}:
\begin{itemize}[leftmargin=*]
  \item \emph{Resample seeds each epoch}: changes subset every epoch (robustness-oriented).
  \item \emph{Fix subset per trial}: keeps one subset during each trial (lower variance).
  \item \emph{Load full graph in memory (no sampling)}: uses all \texttt{train/val} nodes (equivalent to \texttt{sample\_train\_nodes=0} and \texttt{sample\_val\_nodes=0}); higher memory usage.
\end{itemize}

\section{Evaluation, calibration, and artifacts}
\begin{itemize}[leftmargin=*]
  \item \textbf{Evaluation}: \texttt{test} computes F1, AUC, AUPRC, MCC, and confusion matrix.
  \item \textbf{Threshold}: \texttt{pick\_tau\_fbeta} searches threshold \(\tau\) on validation.
  \item \textbf{Calibration}: optional Platt scaling (\texttt{AUTOCALIBRATE\_PROBS}).
  \item \textbf{Persistence}: models \texttt{gat\_model\_BEST*.pt}, \texttt{GraphSMOTE\_embeddings\_model*.pt}, and sidecar \texttt{\_hparams.json}.
  \item \textbf{Graph hash}: \texttt{\_calculate\_graph\_hash} for traceability.
\end{itemize}

\section{Technical audit and best practices}
\subsection{Observed strengths}
\begin{itemize}[leftmargin=*]
  \item Temporal split for \texttt{train/val/test} plus \texttt{sequence\_mask} reduces temporal leakage.
  \item Training-time GraphSMOTE uses \textbf{train} embeddings (\texttt{compute\_train\_embeddings}).
  \item \texttt{NeighborLoader} bounds memory and enables large-graph training.
  \item Cleaning/\emph{coalesce} mechanisms prevent \texttt{edge\_attr} inconsistencies.
  \item Hparams and \emph{run\_id} persistence improve reproducibility.
\end{itemize}

\subsection{Risks and critical points (updated)}
\begin{itemize}[leftmargin=*]
  \item \textbf{Leakage in manual balancing (mitigated)}: \texttt{run\_graphsmote} now restricts embedding/minority pools to \texttt{train\_mask}. Keep auditing this condition.
  \item \textbf{Dependence on \texttt{BIDIRECCTION}}: synthetic edge direction affects message flow and may bias signal propagation. Kept unchanged for now.
  \item \textbf{Gradient accumulation (tunable)}: \texttt{accumulation\_steps} is now configurable (config/UI) but still requires hardware-specific tuning.
  \item \textbf{Balancing + class weights}: class weights are disabled when GraphSMOTE/ImGAGN are active (correct), but validation metric monitoring remains required.
\end{itemize}

\subsection{Prioritized recommendations (current status)}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Implemented}: in manual balancing (\texttt{run\_graphsmote}), restrict to \texttt{train\_mask} to avoid potential leakage.
